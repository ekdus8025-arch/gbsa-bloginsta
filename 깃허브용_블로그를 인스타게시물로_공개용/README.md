# 블로그 글 → 인스타그램 캐러셀 원고

여행 블로그 글 1편을 인스타그램 캐러셀 게시물 1개의 글(슬라이드 원고 · 캡션 · 해시태그)로 바꿉니다.

## 준비물
- Claude Code — 이 폴더를 열고 실행합니다. 작업 지시는 `CLAUDE.md`에 있습니다.
- `rules/` 규칙 파일 5개 — `<상호>`, `<상담 전화>`처럼 `<...>`로 비워 둔 자리를 내 브랜드 값으로 채웁니다.
  - `00_brand.md` 브랜드 정보 · 연락처 · CTA 문구
  - `01_structure.md` 슬라이드 구성 · 장수 · 글자 수
  - `02_tone.md` 문체 · 금지 표현
  - `03_caption.md` 캡션 구조 · 해시태그
  - `04_checklist.md` 검수 체크리스트
- `templates/` 결과물 양식 2개 — `slides_template.md`, `caption_template.md`

## 넣을 자료
- `input/` 폴더에 블로그 원문 1편을 마크다운(`.md`)으로 넣습니다.
- 파일 이름은 `YYYY-MM-DD_주제-영문.md` 형식입니다. (예: `2026-11-25_dubai-family-cost.md`)
  영어 소문자, 숫자, 하이픈(-), 밑줄(_)만 씁니다.
- (선택) `examples/`에 모범 답안을 넣으면 수준과 형식을 참고합니다.

## 시키는 말
```
input/2026-11-25_dubai-family-cost.md 변환해 줘
```
파일 이름은 넣은 원문 이름으로 바꿉니다. `input/`에 원문이 하나뿐이면 `변환해 줘`만 써도 됩니다.

## 결과가 쌓이는 곳
`output/<원문 파일 이름과 같은 폴더>/` 안에 단계마다 파일이 하나씩 생깁니다.

| 파일 | 내용 |
|---|---|
| `01_analysis.md` | 핵심 주제, 타깃, 핵심 정보, 원문 숫자와 출처, 확인 필요 항목 |
| `02_slides.md` | 슬라이드 원고 7~9장 |
| `03_caption_post.md` | 캡션과 해시태그, 그대로 붙여 넣을 업로드용 전체 캡션 |
| `04_review.md` | 체크리스트 검수 결과와 수정 기록 |

글만 만듭니다. 이미지는 만들지 않고, 게시는 사람이 검토한 뒤 직접 합니다.
