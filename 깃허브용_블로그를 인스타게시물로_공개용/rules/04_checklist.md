# 04_checklist.md — 검수 체크리스트

> 4단계 검수에서 쓰는 체크리스트다. 규칙 내용은 각 규칙 파일이 기준이고, 이 파일은 지켰는지만 묻는다.
> 모든 항목은 "예/아니요"로 답한다. 판단 근거를 한 줄씩 남긴다.
> 검수할 파일: `input/` 원문, `01_analysis.md`, `02_slides.md`, `03_caption_post.md`

## 등급
| 등급 | 뜻 | 실패하면 |
|---|---|---|
| 🔴 필수 | 틀리면 고객에게 잘못된 정보가 가거나 브랜드에 문제가 생김 | 반드시 고친다. 고칠 수 없으면 "게시 보류"로 보고 |
| 🟡 권장 | 품질 문제 | 고친다. 고치기 어려우면 이유를 적는다 |
| 👤 사람 확인 | Claude가 확인할 수 없음 | 대표가 직접 확인하도록 목록으로 넘긴다 |

| F1 | 원문의 가격·일정이 지금도 판매 중인 상품 기준과 같은가? (원문 작성 뒤 바뀌었을 수 있음) |

## 검수 결과 작성 형식 (`04_review.md`)
```
# 검수 결과: <폴더명>

## 요약
- 판정: 게시 가능 / 수정 후 게시 가능 / 게시 보류
- 🔴 필수: 통과 N / 실패 N
- 🟡 권장: 통과 N / 실패 N

## 실패 항목과 수정 내용
| 번호 | 문제 | 수정 전 | 수정 후 |
|---|---|---|---|

## 수정하지 못한 항목
| 번호 | 이유 |
|---|---|

## 👤 대표 확인 필요
- F1: (원문에서 확인한 가격·일정 기준을 함께 적는다)
- F2:
- F3:
```

## 판정 기준
- **게시 가능**: 🔴 전부 통과, 🟡 실패 0개
- **수정 후 게시 가능**: 🔴 전부 통과(수정 포함), 🟡 실패가 남아 있으나 이유가 적혀 있음
- **게시 보류**: 🔴 실패를 고치지 못함 (원문 정보 부족 등)
- 어떤 판정이든 F(사람 확인) 항목은 항상 대표에게 넘긴다.
