# 02_tone.md — 문체 규칙

> 인스타그램 게시물의 말투와 문장 규칙이다.
> 슬라이드(결과 파일 `02_slides.md`)와 캡션(결과 파일 `03_caption_post.md`)은 문체가 다르다. 각각 해당 항목을 따른다.
> 브랜드 표기와 금지 주장은 `00_brand.md`, 슬라이드 글자 수는 `01_structure.md`를 따른다.

## 1. 공통 규칙 (슬라이드·캡션 모두)
1. **존댓말로 통일한다.** 반말을 섞지 않는다.
2. **권유하되 재촉하지 않는다.** "~해 보세요"는 쓰고, "지금 바로", "서두르세요"는 쓰지 않는다.
3. **과장·긴급성 문구를 쓰지 않는다.** (4번 금지 표현 목록 참고)
4. **'그래서', '하지만'을 쓰지 않는다.** 필요하면 문장을 나누거나 "다만", "덕분에"로 바꾼다.
5. **표지 제목에 콤마(,)와 세로바(|)를 쓰지 않는다.**
6. **AI식·보고서식 표현을 쓰지 않는다.** ("~에 대해 알아보겠습니다", "결론적으로", "다양한", "특별한 경험")
7. **숫자는 원문 그대로 쓴다.** 줄이거나 반올림하지 않는다. "약", "~대", "최저" 같은 말을 원문에 없는데 붙이지 않는다.
8. **고객 경험담처럼 쓰지 않는다.** ("다녀오신 분들이 모두…", "상담 오신 고객님이…")

## 2. 슬라이드 문체 — "짧고 단정하게"
| 규칙 | 설명 | 예시 |
|---|---|---|
| 어미 | 명사형 끝맺음이나 짧은 "~해요"로 끝낸다. "~합니다", "~하실 수 있습니다"처럼 길게 끝내지 않는다 | ✅ 오전 방문 추천 / ✅ 입장료는 무료예요 |
| 한 장 한 호흡 | 한 문장을 두 장에 걸쳐 쓰지 않는다 | — |
| 숫자 먼저 | 숫자가 핵심이면 문장 앞쪽에 둔다 | ✅ 4박 6일 · 3개국 |
| 목록 | 목록은 풀어 쓰지 않고 그대로 쓴다. 기호는 ✔️ 또는 숫자 1. 2. 3. | ✔️ 여권 유효기간 6개월 |
| 이모지 | 장당 0~1개. 의미를 더할 때만 쓴다. 목록 기호 ✔️와 숫자 1. 2. 3.은 이모지 개수에 넣지 않는다 (📍장소 💰비용 🗓️일정 ✈️항공) | ✅ 💰 4인 가족 비용 |
| 물음표 | 질문형 문장은 표지 또는 공감 슬라이드 중 한 곳에만 쓴다 | — |
| 강조 | 강조할 단어는 한 장에 1개만. 디자인에서 색으로 처리하므로 원고에는 `**굵게**`로만 표시한다 | ✅ 사막 사파리는 **오후 출발** |

## 3. 캡션 문체 — "권유형 대화체"
| 규칙 | 설명 |
|---|---|
| 첫 줄 | "더 보기" 전에 보이는 첫 줄에 핵심 궁금증이나 혜택을 쓴다. 인사말로 시작하지 않는다 |
| 어미 | "~이에요", "~해요", "~해 보세요" 위주의 부드러운 대화체 |
| 문단 | 1~3줄짜리 짧은 문단 3~5개. 문단 사이는 한 줄 띄운다 |
| 이모지 | 문단 앞에 1개 정도. 한 줄에 여러 개를 이어 붙이지 않는다 |
| 역할 | 슬라이드에 못 넣은 조건·기준·참고 정보를 보충한다. 슬라이드 문장을 그대로 반복하지 않는다 |
| 끝맺음 | `00_brand.md` 6번 CTA 문구로 끝낸다 |

## 4. 금지 표현 목록
| 금지 표현 | 이유 | 대신 쓸 표현 |
|---|---|---|
| 파격, 초특급, 역대급, 미친 가격 | 과장 | 원문에 있는 실제 가격·혜택을 그대로 |
| 마감 임박, 선착순, 조기 마감 예상, 지금 아니면 끝 | 긴급성 | 출발일이 정해져 있으면 "1월 출발 일정" |
| 최저가, 업계 최고, 유일한 | 근거 없는 최상급 | 구체적인 특징 ("직항 이용", "4성 호텔 숙박") |
| 인생샷 보장, 후회 없는, 놓치면 후회할 | 약속·상투어 | 실제 장소 정보 ("일몰 시간 18시 전후") — 원문에 있을 때만 |
| ✨여행의 모든 것✨, 완벽 가이드, 총정리 | AI식 상투어 | 무엇을 얻는지 구체적으로 ("비용 3가지만 보면 돼요") |
| ~의 매력에 빠져 보세요, 특별한 추억을 만들어 보세요 | 뜻 없는 권유 | 구체적인 행동 ("오전에 먼저 들러 보세요") |
| ~에 대해 알아보겠습니다, 결론적으로 | 보고서식 | 바로 내용으로 시작 |
| 다양한, 특별한, 다채로운 | 내용 없는 꾸밈말 | 실제 개수나 이름 ("전망대 2곳", "야시장") |
| 그래서, 하지만 | 고정 금지어 | 문장 나누기, "다만", "덕분에" |

## 5. 좋은 예 / 나쁜 예
> 아래 예시의 금액·날짜·포함 사항은 형식을 보여 주기 위한 것이다. 실제 원고에는 원문 정보만 쓴다.

### 표지 (S1)
- ❌ `✨두바이 가족여행의 모든 것✨`
- ✅ `아이랑 두바이 / 비용 이만큼 들어요`

### 정보 슬라이드 (S3)
- ❌ `두바이 사막 사파리는 다양한 액티비티를 즐길 수 있는 특별한 경험으로 많은 분들께 사랑받고 있습니다`
- ✅ `🏜️ 사막 사파리` / `오후 출발 · 저녁 식사 포함` / `아이 동반 가능해요`
  (조건은 원문에 있을 때만)

### 리스트 슬라이드 (S4)
- ❌ `비용은 대략 150만 원대로 저렴한 편입니다`
- ✅ `💰 1인 상품가 1,590,000원` / `2026년 1월 출발 기준`
  (원문에 적힌 금액과 기준 그대로)

### 캡션 첫 줄
- ❌ `안녕하세요 <상호>입니다 😊 오늘은 두바이에 대해 알아보겠습니다!`
- ✅ `아이랑 두바이, 막상 계산해 보면 어디에 돈이 제일 많이 들까요?`

### CTA (S6)
- ❌ `지금 바로 예약하세요! 자리가 얼마 남지 않았어요!`
- ✅ `우리 가족 일정, 편하게 물어보세요` / `📞 <상담 전화>`

## 6. 스스로 점검할 질문
작성을 마치면 아래 질문에 모두 "예"인지 확인한다. 하나라도 "아니요"면 고친다.
1. 소리 내어 읽었을 때 사람이 말하는 것처럼 들리는가?
2. 슬라이드 한 장을 2초 안에 읽을 수 있는가?
3. 4번 금지 표현이 하나도 없는가?
4. 모든 숫자가 원문과 같은가?
5. 캡션이 슬라이드 문장을 그대로 반복하지 않는가?
