# 03_caption.md — 캡션·해시태그 규칙

> 캐러셀 게시물의 캡션(본문 글)과 해시태그 규칙이다.
> 문체는 `02_tone.md` 3번 "캡션 문체"를, 연락처·CTA는 `00_brand.md`를 따른다.
> 결과는 `output/<폴더명>/03_caption_post.md`에 저장한다.
> 캡션은 `02_slides.md`가 완성된 뒤에 쓴다. 슬라이드 문장을 그대로 반복하지 않는다.

## 1. 기본 규격
| 항목 | 규칙 |
|---|---|
| 길이 | 공백 포함 300~800자 (해시태그 제외). 인스타 최대 2,200자를 넘지 않는다 |
| 문단 | 5블록 구조 (2번 참고), 블록 사이는 한 줄 띄운다 |
| 해시태그 | **최대 5개** (인스타 제한). 캡션 맨 끝에 한 줄로 |
| 링크 | URL을 직접 쓰지 않는다. 캡션 링크는 클릭되지 않는다. "프로필 링크"로 안내한다 |
| 계정 태그 | `@<인스타 계정>` 외 다른 계정을 태그하지 않는다 |

## 2. 캡션 5블록 구조

### 블록 1. 첫 줄 후킹 (`caption_hook`)
- 1~2줄, 40자 이내. "더 보기" 전에 보이는 부분이다.
- 표지(S1)와 같은 주제를 **다른 문장**으로 쓴다.
- 질문형이나 "이 게시물에서 얻는 것"을 바로 말하는 문장으로 쓴다.
- 인사말("안녕하세요", "오늘은")로 시작하지 않는다.
- 핵심 키워드(지역명 + 주제)를 첫 줄에 넣는다. 인스타 검색은 캡션 글도 읽는다.
- ✅ `아이랑 두바이 5일, 비용은 어디서 제일 많이 들까요?`
- ❌ `안녕하세요 <상호>입니다 😊`

### 블록 2. 한눈에 요약 (`caption_summary`)
- 2~3줄. 슬라이드에서 무엇을 보여 주는지 짧게 알려 준다.
- ✅ `항공·숙박·입장료를 나눠서 정리했어요. 넘겨 보시면 4인 가족 기준 예상 비용이 나와요.`

### 블록 3. 보충 정보 (`caption_detail`)
- 3~6줄. 슬라이드에 넣지 못한 정보를 쓴다.
  - 가격의 기준과 조건 (출발일, 인원, 포함·불포함)
  - 운영 시간, 계절, 예약 시 참고 사항
- 원문에 있는 정보만 쓴다. 조건이 원문에 없으면 쓰지 않는다.
- 짧은 목록(✔️) 3개까지 허용한다.
- 상품 정보에는 "상품가·일정은 출발일에 따라 달라질 수 있어요"를 넣는다. 원문에 같은 뜻의 문장이 있으면 원문 표현을 쓴다.

### 블록 4. 저장·공유 유도 (`caption_save`)
- 1줄. 재촉하지 않고 쓸모를 말한다.
- ✅ `여행 준비할 때 다시 보시려면 저장해 두세요 📌`
- ✅ `같이 가실 가족에게 공유해 보세요`
- ❌ `저장 안 하면 손해!`

### 블록 5. CTA (`caption_cta`)
- 1~2줄. `00_brand.md` 6번 CTA 기본 문구 중 1~2개를 쓴다.
- 기본 조합: 전화형 + 링크형
  ```
  궁금한 일정은 편하게 물어보세요 📞 <상담 전화>
  상품 일정은 프로필 링크에서 확인하실 수 있어요
  ```

## 3. 해시태그 규칙

### 개수와 위치
- 결과 파일에서는 `hashtags` 칸에 쓴다.
- **최대 5개.** 6개 이상은 업로드되지 않는다.
- 캡션 맨 끝, CTA 다음 줄에 한 줄로 쓴다.
- 댓글에 따로 달지 않는다.

### 5칸 구성
| 칸 | 종류 | 예시 (두바이 가족여행) | 예시 (동유럽·발칸) |
|---|---|---|---|
| 1 | 지역 | #두바이여행 | #발칸여행 |
| 2 | 지역 + 주제 | #두바이가족여행 | #동유럽발칸 |
| 3 | 타깃·여행 방식 | #아이랑해외여행 | #부부여행 |
| 4 | 게시물 형식·쓸모 | #여행경비 | #패키지여행 |
| 5 | 브랜드 (고정) | #<브랜드> | #<브랜드> |

### 고르는 원칙
1. **구체적인 태그를 고른다.** #여행, #travel, #일상 같은 너무 넓은 태그는 쓰지 않는다.
2. **게시물 내용과 맞는 태그만 쓴다.** 원문에 없는 지역·주제 태그를 넣지 않는다.
3. **한국어 태그를 기본으로 한다.** 타깃이 한국 고객이다.
4. **띄어쓰기 없이, 특수문자 없이 쓴다.** (#두바이 가족여행 ❌ → #두바이가족여행 ✅)
5. **금지 태그**: #최저가, #특가, #땡처리, #마감임박, #<본사>공식, #협찬 등 `00_brand.md`·`02_tone.md` 금지 표현이 들어간 태그
6. 같은 태그 묶음을 매번 똑같이 쓰지 않는다. 5번 칸(#<브랜드>)만 고정한다.

## 4. 완성 형태 예시
```
아이랑 두바이 5일, 비용은 어디서 제일 많이 들까요?

항공·숙박·입장료를 나눠서 정리했어요.
넘겨 보시면 4인 가족 기준 예상 비용이 나와요.

✔️ 2026년 1월 출발 기준이에요
✔️ 사막 사파리는 상품가에 포함돼요
✔️ 상품가·일정은 출발일에 따라 달라질 수 있어요

여행 준비할 때 다시 보시려면 저장해 두세요 📌

궁금한 일정은 편하게 물어보세요 📞 <상담 전화>
상품 일정은 프로필 링크에서 확인하실 수 있어요

#두바이여행 #두바이가족여행 #아이랑해외여행 #여행경비 #<브랜드>
```
> 위 예시의 기준일·포함 사항은 형식을 보여 주기 위한 것이다. 실제 캡션에는 원문 정보만 쓴다.

## 5. 스스로 점검할 질문
1. 첫 줄만 읽어도 무슨 게시물인지 알 수 있는가?
2. 캡션에 원문에 없는 숫자·조건이 없는가?
3. 슬라이드 문장을 그대로 복사한 줄이 없는가?
4. URL을 직접 쓰지 않았는가?
5. 해시태그가 5개 이하이고, 마지막이 #<브랜드>인가?
